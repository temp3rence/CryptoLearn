Кратко про режимы

                
    
                    
  • Text: plaintext шифруется как строка; удобно видеть результат глазами.
    • 
                    
  • File: файл читается как байты → Base64 → шифруется так же, как текст.
    • 
                    
  • На сервере нет разницы между текстом и файлом — всегда шифруются байты.
